## Export procedure (every phase ends with this)
Run in the project root and check the zip contains docs/, package.json and the lockfile:
```
zip -r meyou-src.zip . -x "node_modules/*" ".git/*" ".expo/*" "*.zip" "*.apk" "*.aab" "dist/*" ".cache/*" ".local/*" ".upm/*"
```
- U27 does not build an APK; follow the current EAS APK steps in `README.md` when preparing a device preview.
- The web preview may be blank: the app is Android-only. Not a bug.

## Checks that must pass before exporting
`pnpm typecheck`, the complete `pnpm test` chain in `package.json`, and `npx expo export --platform android --max-workers 1 --no-bytecode` (Android bundling).
If pnpm refuses an install because of `minimumReleaseAge`, do NOT disable the policy: run `pnpm clean --lockfile` then `pnpm install`. `npx expo install` does not work in the sandbox (its API is blocked): add packages with `pnpm add <pkg>@~57.x` using the SDK 57 version.

- `src/server/`, `src/backup/` — server client (`ServerClient`, connection test and its error codes, QR/link parsing, token store) is live since S2; browsing/thumbnails/video through `ServerProvider` is live since S4; backup/upload (`src/backup/*`: scan, queue, rules, watcher) is live since S6.
